# Backrooms Fabric Mod (Minecraft 1.21.1)

A feature-rich Fabric mod designed to recreate the unsettling, liminal atmosphere of "The Backrooms" in Minecraft.

## Features
- **Custom Blocks**: Yellow Walls (with variants), Flickering Lamps (dynamic light & particle effects), Cardboard Boxes (custom hitboxes & loot).
- **Atmosphere & Ambience**: Custom fog, constant background hum, random 3D positional creaks, and sudden jump-scare noises.
- **Visual Effects**: Screen distortion (nausea-lite) and dynamic edge noise / camera grain.
- **Event System & GUI**: Item collection ("Exit Fragments"), Exit Door, and a comprehensive Admin Menu (`/backrooms menu`) with sync via Fabric Networking and persistent JSON config.

---

## Building via GitHub Actions
1. Push this repository to GitHub.
2. Go to the **Actions** tab in your GitHub repository.
3. Select the **Build Mod** workflow and click **Run workflow**.
4. Once completed, download the compiled `.jar` artifact from the run summary and drop it into your Minecraft `mods` folder!
